01 / Проблема

Заменить ручную сборку листов воспроизводимым pipeline

Готовые 3D‑решения не закрывали специализированный 2D‑выпуск. Нужен был собственный контур, в котором данные управляют геометрией, слои и сущности формируются предсказуемо, а изменения можно повторно провести через весь комплект без ручной пересборки каждого листа.

01

Управляемые изменения

Один источник данных позволяет пересобрать геометрию без ручного редактирования каждого листа.

02

Пакетный выпуск

Файлы создаются и конвертируются без последовательного открытия в AutoCAD.

03

Диагностика

CSV, JSON и preview показывают, на каком этапе возникло отклонение.

04

Контроль смысла

Машина находит подозрительную геометрию, а человек проверяет инженерную корректность.

02 / Личный вклад

Предметную задачу перевёл в критерии автоматизации

Ценность кейса — не в самом факте генерации файла, а в правильно заданных требованиях к составу листов, повторяемости выпуска и контролю результата.

Александр / owner

Требования, запуск и visual QA

Определял нужные листы и элементы, вручную запускал AutoCAD‑контур, сравнивал результат с ожиданиями, отклонял визуально слабые версии и требовал воспроизводимой проверки. Для публичного demo подтвердил реальную 2D‑проблему и согласовал synthetic-only границы.

05 / Публичная реконструкция

Безопасная публичная версия показывает метод целиком

Чтобы показать pipeline без дипломных листов и закрытых расчётов, собран новый dependency‑free Python demo: одна JSON‑модель выпускает DXF, SVG, CSV и HTML/JSON QA report. AutoCAD Core Console 2022 реально импортировал DXF и создал DWG 2018. Репозиторий подтверждает воспроизводимость подхода и способность принимать AI‑assisted реализацию по наблюдаемому результату.

06 / Ценность для команды

Что получает команда от такого подхода

  • Изменение исходных данных можно провести через комплект без ручной пересборки каждого листа.
  • Пакетный выпуск сокращает число однотипных действий в AutoCAD.
  • CSV, JSON и preview помогают локализовать дефект до финального просмотра.
  • Проверяемые промежуточные форматы позволяют развивать pipeline поэтапно.
  • Автоматизированный геометрический QA дополняет инженерную проверку, не подменяя её.

07 / Границы

Граница кейса и следующий уровень

  • Кейс относится к 2D‑чертежам; 3D‑автоматизация не заявляется.
  • Это учебный дипломный контур и portfolio demo, а не коммерческий CAD‑продукт.
  • Код автоматизации, тесты и текущие публичные коммиты созданы Codex; личная самостоятельная реализация Александром не доказана.
  • Нулевые пересечения — результат конкретного машинного отчёта, а не гарантия полного соответствия всей рабочей документации.
